Resolución paso a paso

Bloque 1 · Primer principio para gas ideal (sistema cerrado)

Figura · Sistema cerrado: la masa no cruza la frontera
Qnet,in − Wnet,in = ΔU = m·cv·(T₂ − T₁)  |  R = cp − cv
  1. Datos y supuestos: gas ideal (P·v = R·T), sistema cerrado (m = constante), ΔKE = ΔPE = 0.
  2. Propiedades: identifica el gas y toma cv, cp a T promedio; verifica R = cp − cv.
  3. Masa (fuente única): si la masa está fijada úsala tal cual; si no, se obtiene de V₁ con m = P₁·V₁/(R·T₁). Nunca las dos a la vez.
  4. Balance de energía: Qnet,in − Wnet,in = ΔU. Con Wnet,in y Qnet,in conocidos despeja T₂:
T₂ = T₁ + (Qnet,in − Wnet,in) / (m·cv)   ⇒   V₁ = m·R·T₁/P₁
SignoLectura física
Qnet,in > 0El sistema recibe calor (se calienta).
Qnet,in < 0El sistema entrega calor (se enfría).
Wnet,in > 0Trabajo neto entra (compresión / eje motor).
Wnet,in < 0Trabajo neto sale (expansión / motor).

Nota: ΔU y ΔH dependen solo de ΔT en gas ideal. Si ΔT > 0 entonces ΔU, ΔH > 0 aunque haya flujo de calor mixto.

Bloque 2 · Proceso isocórico (v = constante, Wb = 0)

Figura · Recipiente rígido: V₁ = V₂
Wb = 0  ⇒  Qnet,in = ΔU = m·cv·(T₂ − T₁)  |  P₂/T₂ = P₁/T₁
  1. Datos: V₁ = V₂ (tanque rígido), P₁, T₁, T₂ y m (o V₁ con la fuente única de masa).
  2. Volumen: V₁ = m·R·T₁/P₁ = V₂. En este caso el volumen sí se reporta en resultados.
  3. Trabajo de frontera: Wb = ∫P dV = 0 porque dV = 0 (no hay eje ni expansión).
  4. Energía: Qnet,in = ΔU = m·cv·(T₂ − T₁). Con We,in del agitador: Qnet,in = ΔU − We,in.
  5. Presión final (ley de Gay-Lussac): P₂ = P₁·T₂/T₁ (V constante ⇒ P ∝ T).
  6. Verificación: si T₂ > T₁ entonces Qnet,in > 0 y P₂ > P₁.
P₂ = P₁·(T₂/T₁)   ·   Qnet,in = m·cv·ΔT − We,in   ·   [kJ] = [kg]·[kJ/kg·K]·[K]

Bloque 3 · Proceso isobárico (P = constante) — masa y volúmenes

Figura · Émbolo a presión constante: P·V = m·R·T
Wb = P·(V₂ − V₁) = m·R·(T₂ − T₁)  |  Qnet,in = ΔH − We,in
  1. Datos: P (constante), T₁, T₂, We,in y una sola fuente de masa: m fijado o V₁ con m = P·V₁/(R·T₁).
  2. Volúmenes (siempre se reportan): V₁ = m·R·T₁/P y V₂ = m·R·T₂/P.
  3. Trabajo de frontera: Wb = P·(V₂ − V₁) = m·R·(T₂ − T₁). Sale del sistema si T₂ > T₁.
  4. Energía interna y entalpía: ΔU = m·cv·ΔT, ΔH = m·cp·ΔT.
  5. Calor neto: Qnet,in = ΔH − We,in (a P constante el calor es la variación de entalpía menos el trabajo del eje).
  6. Verificación dimensional: [kJ] = [kPa]·[m³] = [kg]·[kJ/kg·K]·[K].
SituaciónRelaciónConsecuencia
CalentamientoT₂ > T₁V₂ > V₁, Wb > 0 (expansión)
EnfriamientoT₂ < T₁V₂ < V₁, Wb < 0 (compresión)

Regla de la fuente única de masa: el campo m y el campo V₁ nunca mandan a la vez. El interruptor «Sistema cerrado: obtener m de V₁» decide quién es la fuente; el otro queda bloqueado y el resultado muestra siempre V₁ y V₂.

Bloque 4 · Proceso politrópico (P·vn = constante)

Figura · Compresión politrópica de un gas en un cilindro
Wb = (P₂V₂ − P₁V₁)/(1 − n) = m·R·(T₂ − T₁)/(1 − n)
  1. Datos: P₁, T₁, T₂, n, We,in y la fuente única de masa (m o V₁).
  2. Relación de estados: T₂/T₁ = (P₂/P₁)(n−1)/n ⇒ Π = P₂/P₁ = (T₂/T₁)n/(n−1).
  3. Volumen: V₁ = m·R·T₁/P₁ y V₂ = V₁·(T₂/T₁)1/n (o V₂ = m·R·T₂/P₂).
  4. Trabajo: Wb = m·R·(T₂ − T₁)/(1 − n). Casos: n → 1 isótérmico, n = k adiabático.
  5. Energía: ΔU = m·cv·ΔT y Qnet,in = ΔU + Wb − We,in.
  6. Verificación: si n > 1 y T₂ < T₁ (compresión) la curva sube: P₂ > P₁.
Π = (T₂/T₁)n/(n−1)  ·  V₂ = V₁·(T₂/T₁)1/n  ·  Qnet,in = m·cv·ΔT + Wb − We,in
nProcesoNota
n = 1IsotérmicoWb = m·R·T·ln(V₂/V₁) (fórmula aparte)
n = k = cp/cvAdiabáticoQ = 0 si además no hay eje
1 < n < kPolitrópico típicoCompresión con enfriamiento intermedio

Dónde vive el primer principio

Cuatro escenarios industriales para motivar la clase. Cada botón abre el caso de la pestaña Resolver con la idea central cargada.

Compresores de tornillo

Aire a presión para herramientas. Cerca de isentrópico: el compresor entrega trabajo y el gas sube su entalpía (ΔH = m·cp·ΔT). Caso politrópico con n ≈ k.

Turboventiladores (HVAC)

El aire se mueve a P ≈ constante en el evaporador/condensador: Qnet,in = ΔH. Por eso en climatización se usa la entalpía como balance energético. Caso isobárico.

Autoclaves y hornos

Recipiente rígido: V = constante ⇒ Wb = 0. Todo el calor aportado se vuelve energía interna del producto (Q = ΔU). Caso isocórico.

Calentador eléctrico

El aire queda a P = constante (émbolo con peso): la resistencia entrega We,in, el aire se expande y Qnet,in = ΔH − We,in. Caso isobárico.
